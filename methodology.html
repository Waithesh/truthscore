How the TruthScore Score Works

Written because a creator we asked to review the product asked, reasonably, to see this before recommending it to anyone. This page describes what the code actually does, not a simplified marketing version of it.

Three signals, blended

Every score is a weighted average of up to three independent checks. Not every video gets all three — the weights below re-normalize automatically so a missing signal doesn't silently drag the score toward zero.

SignalWeightWhat it checks
YouTube signals55%Title/description keyword patterns (unrealistic income claims, urgency language), engagement ratio vs. view count, comment sentiment, channel age, and — where available — the video's real dislike count (YouTube hid public dislikes in 2021; we pull the underlying number back via the ReturnYouTubeDislike API).
Web cross-reference30%An AI model with live Google Search access looks for scam reports, complaints, fact-checks, or forum discussion of this specific video or channel anywhere on the web — not just on YouTube. This is what can catch a channel that looks clean by every YouTube metric but has a documented bad reputation elsewhere.
Transcript analysis15%When captions are available, the same AI model reads the actual spoken content for manipulation patterns — vague "secret method" claims, fear-based pressure, cult-like in-group language. Most videos don't have usable captions, so this signal is a bonus, not a requirement.
Where the "Sources Checked" links come from: when the web cross-reference runs, the underlying search tool returns the actual pages it visited to reach its conclusion. We show you those exact links — not a domain name the model typed out — specifically so you can open them and judge the evidence yourself instead of trusting our summary of it.

What this can get wrong

Being direct about the honest failure modes, because a tool like this is only useful if you know when not to trust it:

  • The web cross-reference depends on things already being written about a video or channel somewhere. A brand-new scam with no complaints filed yet will score better than it deserves, simply because there's nothing to find yet.
  • Keyword-based signals can be fooled by phrasing. A legitimate creator who uses urgency language ("last chance to enroll") will get flagged the same as someone using it manipulatively — the flag notes the pattern, it doesn't prove intent.
  • The dislike count comes from a third-party API (ReturnYouTubeDislike), not YouTube directly, since YouTube stopped exposing it publicly in 2021. It's a well-established community tool, but it's estimating a number YouTube itself no longer confirms.
  • None of this replaces your own judgment. The score is a set of probabilistic signals, not a verdict. Read the flags and the sources, not just the number.

Data freshness

Scans are cached for 6 hours to control API costs, so re-scanning the same video shortly after someone else did will return the same result rather than re-running every check.
